# FacturaScripts
Software ERP de código abierto de facturación y contabilidad para pequeñas y medianas empresas. Construido sobre PHP, con Twig y Bootstrap 5. Fácil y potente.

# PunteoCuentasPlus
Plugin para FacturaScripts que amplía el punteo de subcuentas contables incluido en el core. Facilita la conciliación manual de subcuentas, como las de bancos o caja, y permite corregir movimientos registrados en una subcuenta equivocada.

## Funcionalidades
- **Totales de comprobados y no comprobados**: la ficha de la subcuenta muestra el saldo de los movimientos comprobados y el de los pendientes.
- **Filtro por estado**: la lista de movimientos se puede filtrar por comprobados, no comprobados o todos, combinándolo con el resto de filtros.
- **Impresión de movimientos**: activa el botón Imprimir en la lista de movimientos de la subcuenta, con los filtros aplicados.
- **Cambio masivo de subcuenta**: traslada los movimientos seleccionados a otra subcuenta del mismo ejercicio, incluidos los de asientos generados desde facturas u otros documentos.
- **Archivos adjuntos**: permite guardar en la subcuenta extractos, arqueos o justificantes, con observaciones y vista previa de imágenes, vídeos y PDF.

## Requisitos
- FacturaScripts 2026.6 o superior.
- PHP 8.1 o superior.

## Nombre de carpeta
Como con todos los plugins, la carpeta se debe llamar igual que el plugin. En este caso **PunteoCuentasPlus**.
